## 3. 跳过项说明（重要）

`Skipped: 1` 是 **设计性跳过**，不是失败：

- 类：`com.shortlink.idgenerator.IdGeneratorBenchmarkTest`
- 原因：标注了 `@EnabledIfSystemProperty(named = "shortlink.benchmark", matches = "true")`，默认不执行（它是发号器横向性能对比，需要真实 MySQL/Redis，属于压测基准而非单测）
- 需要时手动执行：`mvn -B test -Dtest=IdGeneratorBenchmarkTest -Dshortlink.benchmark=true`

**因此口径应记作**：`198 run / 0 fail / 0 error / 1 skip(设计性)`，不能写成"198 全绿无跳过"。
