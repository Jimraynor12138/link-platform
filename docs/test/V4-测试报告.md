## 1. 测试目标

1. **多租户隔离**：租户只看到自己的数据，平台管理员看全量，跳转免租户。
2. **渠道归因**：创建带 channel，落库正确，统计按渠道聚合。
3. **开放 API**：签名合法通过、错签 401、配额超限 429。
4. **跳转防刷**：单 IP 对同短码窗口内去重。
5. **无回归**：存量单测保持全绿。

## 5. 结论

- ✅ **多租户隔离**：管理链路按租户过滤、平台看全量、跳转免租户，三条语义都有单测 + E2E 双重验证
- ✅ **渠道归因 + 开放 API + 跳转防刷**：全部实测通过
- ✅ **无回归**：254 单测全绿
- ⚠️ **已知遗留**（文档已注明）：
  - core 信任 `X-Tenant-Id`（直连可伪造），彻底隔离靠 P7 网络层（台账 P3-1）
  - API Key secret 存明文（HMAC 验签需要可检索），生产应加密存储
  - P4 签名只签请求头未签 body，生产应把 body 纳入签名抗篡改
