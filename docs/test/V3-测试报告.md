# V3（P3）测试报告

> 版本：V3（P3 Gateway 路由/鉴权/限流 + Sentinel）｜ 日期：2026-10-16
> 环境：JDK 17 · Maven 3.9.5 · Windows · MySQL 8（`link_platform`）· Redis db 1 · Nacos 2.4.2（Docker）

---

## 1. 测试目标

1. **鉴权前置可用**：经网关登录/访问受保护接口；无 token 401；伪造身份头无效。
2. **路由正确**：`/auth/**`、`/api/v1/**`、`/{code}` 命中正确服务；`/internal/**` 不暴露。
3. **两层限流**：网关入口限流（429）+ 服务细粒度限流（A0429）。
4. **熔断降级**：下游（auth）不可用时，core 通过 Feign fallback 优雅降级。
5. **无回归**：存量单测保持全绿。

- ✅ **鉴权前置 + 身份透传**：全链路通，且**伪造头被剥离**这一安全关键点有单测 + E2E 双重验证

- ✅ **两层限流 + 熔断降级**：服务层 A0429、网关层 429、Feign fallback 均实测通过
- ✅ **无回归**：236 单测全绿
